# cro-pdp-audit

[English](README.md) | 简体中文

一个审电商产品详情页转化率的 AI Skill：把整个页面拆成 12 个部分打分（满分 100），标出跨页面的风险信号，找出最拖销量的 5 个问题，每个都给具体改法，按投入产出比排好先后。

给它截图、网址或设计稿都行。可以作为 Claude 的 Skill 使用，也可以给任何能读 Markdown 指令文件的 AI 工具用。

## 检查什么

| 部分 | 分值 | 看什么 |
|---|---|---|
| 首屏 | 12 | 标题、副标题、首图、价格、评分，8 秒内能不能看明白 |
| 图片 | 12 | 细节图、尺寸参照图、使用场景图、买家实拍、手机端滑动体验 |
| 视频 | 8 | 是演示而不是品牌广告、开头 3 秒、字幕、位置 |
| 利益大于功能 | 15 | 讲结果而不是堆参数；维生素型还是止痛药型的定位 |
| 社交证明 | 12 | 评分、详细且新近的评价、买家图、评分是否可信 |
| FAQ | 5 | 运费、退货、尺寸适配、保养、这个品类最常被问的问题 |
| 信任与风险兜底 | 8 | 退货政策可见、运费清楚、保证承诺、联系方式、稀缺是否真实 |
| 加购按钮 | 10 | 文案具体、手机端吸底、颜色对比、按钮下方的安心话术 |
| 设计层级 | 8 | 对比度、字号、层级、留白、不用横向标签页 |
| 手机端 | 5 | 速度、点击区域、图片缩放、弹窗 |
| 营销钩子 | 3 | 真实稀缺、诱饵定价、组合优惠，不能造假 |
| 关联推荐 | 2 | 相关的「经常一起买」，写明省多少 |

另外还有 7 个红黄绿信号灯（品类适配、风格一致、受众匹配、本地化、评价新近度、可扫读性、认知负担）、改写对照表、最多 5 条按投入产出比排序的下一步，以及一个 50 条的快速扫描模式。

完整示例见[示例审计](examples/sample-audit.md)。

## 好在哪里

- **打分有标尺。** 每个部分都写明了评分档位和标准扣分项，同一个页面审两次，结果不会差太远。
- **讲证据，不讲感觉。** 内置证据库，收录 Baymard、Nielsen Norman Group、PowerReviews、西北大学 Spiegel 研究中心、BrightLocal、斯坦福网站可信度研究、VWO 和 Unbounce 的测试、WCAG 和苹果设计规范等。它能说清每个改动「为什么值得做」，每个数字都标了出处和可信度等级。
- **不造假证据。** 改写里用 `[真实评分]`、`[真实评价数]` 这类占位符，Skill 被明确要求不得编造评价、评分、销量或媒体报道。
- **有优先级。** 只给 5 个改动，按回报排序，每个都能照着直接做。

## 安装

**Claude：** 把 `skills/cro-pdp-audit/` 复制到 `~/.claude/skills/`（或项目里的 `.claude/skills/`），然后发一张截图并说：

> 从转化角度审一下这个产品页。

**其他 AI 工具：** 把 `skills/cro-pdp-audit/SKILL.md` 作为指令文件，参考文件会按需读取。

## 文件结构

```
skills/cro-pdp-audit/
├── SKILL.md                  # 审计流程、输出模板、审计铁律
└── references/
    ├── sections.md           # 12 个部分的评分标尺
    ├── evidence.md           # 研究数据与公开测试，附出处和可信度等级
    └── checklist.md          # 50 条快速扫描清单
examples/
└── sample-audit.md           # 完整审计示例（虚构产品）
```

## 证据等级

**A**：已对照原始出处核实。**B**：出处明确且可信。**C**：流传很广但难以追溯原始研究，Skill 引用时必须说明「常被引用」。别人的测试结果只作参考，不会被当成对你页面的效果预测。有更好的出处欢迎提 issue。
